# План

Текущий объём: часть Лёши на 1С:Элементе. Целевой MVP по исходной спецификации — 29 ноября 2026; 30 ноября — резерв; выступление — 16 декабря. Это целевые даты из предоставленного документа.

| Этап | Ответственный | Проверяемый результат | Статус |
|---|---|---|---|
| Подготовка репозитория и Codex | Лёша + Codex | Клон, skills, окружение, локальная проверка | Выполнено; подробности в docs/SETUP.md |
| Проектирование, 17 ноября | Лёша + Codex | Модель, транзакции, контракт, источники и матрица проверок | Проект подтверждён прямыми проверками API. Согласование с Линой впереди |
| Модель и контракт, 17–19 ноября | Лёша; контракт вместе с Линой | Реальные метаданные, проверенные транзакции и уникальность; согласованные payload и ответы | A/B/C и UI опубликованы. Контракт подключения подготовлен |
| Минимальный HTTP API, 17–19 ноября | Лёша | Принять сообщение → сохранить → обработать C → прочитать настоящий Order | Работает в dev. Актуальный API в docs/ELEMENT_HANDOFF.md |
| Сквозная интеграция | Лина + Лёша | Python → RabbitMQ → HTTPS Элемента → заказ | Проверена цепочка с генератором Лины и проверочным потребителем. Остались итоговый адаптер и служебный Bearer |
| Сбои и базовый интерфейс, 20–22 ноября | Лёша | До commit / после commit, журнал и реальные статусы | Откат и модель потери ответа проверены по HTTP. Overview читает метрики прогона |
| Стратегии и проверки, 23–25 ноября | Вместе | Изолированные A/B, проверка окна гонки B, конкурентные повторы C | На стороне Элемента проверено 23 ноября. Поведение адаптера предстоит подтвердить совместно |
| Эксперименты и материалы, 26–29 ноября | Лина; Лёша проверяет техническую часть | Сохранённые результаты, воспроизводимость, статья и демо | Не начато |

Первый этап реализации: уточнить физические HTTP-маршруты и возможности платформы, спроектировать и создать данные, затем опубликовать минимальный API и проверить его прямым HTTP-запросом. Python-компоненты не входят в текущую работу.

Проект для реализации: [ARCHITECTURE.md](docs/ARCHITECTURE.md), [CONTRACT.md](docs/CONTRACT.md), [TEST_PLAN.md](docs/TEST_PLAN.md). Прочитанные официальные источники и ограничения проверки: [ELEMENT_RESEARCH.md](docs/ELEMENT_RESEARCH.md). Результаты прямой приёмки находятся в experiments/acceptance/. Следующий этап — подтвердить служебную авторизацию, пройти цепочку с Линой и собрать экспериментальные данные.
