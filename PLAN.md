# План

Текущий объём: часть Лёши на 1С:Элементе. Целевой MVP по исходной спецификации — 29 ноября 2026; 30 ноября — резерв; выступление — 16 декабря. Это целевые даты из предоставленного документа.

| Этап | Ответственный | Проверяемый результат | Статус |
|---|---|---|---|
| Подготовка репозитория и Codex | Лёша + Codex | Клон, skills, окружение, локальная проверка | Выполнено; подробности в docs/SETUP.md |
| Проектирование, 17 ноября | Лёша + Codex | Модель, транзакции, контракт, источники и матрица проверок | Выполнено в docs; runtime не проверен, контракт с Линой не согласован |
| Модель и контракт, 17–19 ноября | Лёша; контракт вместе с Линой | Реальные метаданные, проверенные транзакции и уникальность; согласованные payload и ответы | Первый срез реализован и скомпилирован; расширение A/B и UI впереди |
| Минимальный HTTP API, 17–19 ноября | Лёша | Принять сообщение → сохранить → обработать C → прочитать настоящий Order | Реализовано и проверяется live; см. docs/FIRST_SLICE.md |
| Сквозная интеграция | Лина + Лёша | Python → RabbitMQ → HTTPS Элемента → заказ | Зависит от частей обоих авторов |
| Сбои и базовый интерфейс, 20–22 ноября | Лёша | До commit / после commit, журнал и реальные статусы | Не начато |
| Стратегии и проверки, 23–25 ноября | Вместе | Изолированный A, B с проверкой гонки, C с конкурентными повторами | Не начато |
| Эксперименты и материалы, 26–29 ноября | Лина; Лёша проверяет техническую часть | Сохранённые результаты, воспроизводимость, статья и демо | Не начато |

Первый этап реализации: уточнить физические HTTP-маршруты и возможности платформы, спроектировать и создать данные, затем опубликовать минимальный API и проверить его прямым HTTP-запросом. Python-компоненты не входят в текущую работу.

Проект для реализации: [ARCHITECTURE.md](docs/ARCHITECTURE.md), [CONTRACT.md](docs/CONTRACT.md), [TEST_PLAN.md](docs/TEST_PLAN.md). Прочитанные официальные источники и ограничения проверки: [ELEMENT_RESEARCH.md](docs/ELEMENT_RESEARCH.md). Первый серверный срез реализован; подтверждённые результаты и ограничения — в docs/FIRST_SLICE.md и experiments/acceptance/. Следующая реализация: A/B, метрики и Operations UI.
