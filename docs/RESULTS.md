# Результаты сравнения A, B и C

25 ноября 2026 года проведено девять сквозных прогонов по 100 синтетических операций на RabbitMQ 4.2.9 и опубликованном Элементе 10.0.7-28, сборка приложения 1.0-13. Для каждого из трёх seed (`101`, `102`, `103`) стратегии получали один и тот же набор бизнес-полей. Каждый прогон имел собственные идентификаторы, очереди и журналы. Три независимых потребителя одновременно работали с одним развёртыванием и одним брокером. HTTP-клиенты использовали действующую сессию администратора dev.

Сценарий моделировал потерю успешного ответа после фиксации заказа. Первый успешный ответ намеренно отбрасывался для каждой операции. Адаптер фиксировал неопределённость и применял выбранную политику. После завершения отдельный GET по каждой операции подтвердил число документов и их ссылки. [Описание эксперимента](EXPERIMENT.md)

| Результат за 3 прогона | A | B | C |
|---|---:|---:|---:|
| Операции | 300 | 300 | 300 |
| Операции с хотя бы одним заказом | 300 | 300 | 300 |
| Операции с ровно одним заказом | 0 | 300 | 300 |
| Лишние заказы | 300 | 0 | 0 |
| Клиент наблюдал UNKNOWN | 300 | 300 | 300 |
| UNKNOWN к завершению | 0 | 0 | 0 |
| HTTP-вызовы адаптера | 900 | 900 | 900 |

В B к моменту чтения исходный заказ уже был сохранён, поэтому адаптер подтвердил его через GET. Эта постановка не проверяет окно гонки. В отдельной [прямой приёмке Элемента](../experiments/acceptance/2026-11-23/element-abc-api.json) сохранено другое упорядочивание, где B прочитал состояние до фиксации исходной попытки, затем повторил команду и получил дубль. При том же упорядочивании C сохранил один заказ.

Проверены также обычный путь, откат до фиксации и публикация второй копии сообщения по два заказа на стратегию. При исчерпании лимита потребитель отклонил доставку без ACK, брокер перенёс её в очередь `.unresolved`, а независимый GET при этом обнаружил сохранённый заказ. Отдельный запуск после закрытия канала без ACK обработал доставку с `redelivered` и подтвердил тот же документ. [Журнал дополнительных проверок](../experiments/comparison/2026-11-25/acceptance.json)

- [CSV по каждому прогону](../experiments/comparison/2026-11-25/summary.csv) содержит объёмы, повторы, p50/p95 и число наблюдений.
- [Сравнительный график](../experiments/comparison/2026-11-25/comparison.png) построен по всем девяти сериям.
- [Архив входов, событий и сверки заказов](../experiments/comparison/2026-11-25/raw-runs.tar.gz) и [индекс с версиями и SHA-256](../experiments/comparison/2026-11-25/index.json) позволяют перепроверить каждую серию.

За наблюдаемое время восстановления отвечает и фиксированная пауза адаптера 100 мс между попытками. Полученные задержки зависят от выбранного развёртывания и совместной нагрузки. Результаты относятся к моделируемому сбою и указанной конфигурации.
