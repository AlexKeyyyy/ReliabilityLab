Это основание для проектирования. Рабочее приложение, его HTTP-адрес, доступные разрешения и конкретные сгенерированные типы пока не проверены. Синтаксис конструкторов регистра/блокировки сверяется при создании метаданных, затем компилируется в Элементе.

Справочники установленных skills использованы как дополнительная инженерная опора: `xbsl-meta-add/references/HttpСервис.md`, `Документ.md`, `РегистрСведений.md`. При расхождении приоритет у документации 10.0 и компилятора платформы.

## Локальная авторизация

По запросу пользователя сохранена запись для `1cmycloud.com` в `~/.netrc`, права 600. Значения не копируются в проект, документацию или команды в README. Не применять этот пароль как ClientSecret бизнес-API. Для HTTP-клиента, работающего с OAuth-маршрутами, отключать автоматическую подстановку netrc в Basic-заголовок; вход в справку выполняется штатным механизмом сайта.
